# Free Parking

Готовая веб-карта на базе **Leaflet** с полностью локальными данными.

- Улицы из списка зоны `1.2` подсвечиваются **синим**.
- Улицы из списка зоны `Б.1` подсвечиваются **зелёным**.
- Геометрия улиц уже сохранена локально в `data/belgrade-streets-offline.js`.

## Запуск

1. Откройте терминал в папке проекта.
2. Запустите локальный сервер:

```bash
python3 -m http.server 8080
```

3. Откройте в браузере:

[http://localhost:8080](http://localhost:8080)

## Файлы

- `index.html` — вся логика карты и интерфейс.
- `data/belgrade-streets-offline.js` — локальные данные линий улиц (офлайн, подключается как script).
- `vendor/leaflet/*` — локальные файлы Leaflet (без CDN).
- `tiles/*` — локальные OSM-тайлы подложки (z15–z19; z17–z19 для центральной зоны).
- `scripts/build_offline_data.mjs` — одноразовая генерация офлайн-данных из Overpass (для обновления набора).
- `scripts/download_offline_tiles.mjs` — одноразовая загрузка офлайн-тайлов подложки.

## Как пользоваться

- Карта по умолчанию загружает улицы из локального `data/belgrade-streets-offline.js`.
- Базовая подложка карты загружается из локальных файлов `tiles/*`.
- Сеть для отображения улиц не требуется.
- Слева можно искать улицу по названию.
- Клик по строке улицы в списке делает фокус карты на найденном участке.
- Кнопка `Location` в правом нижнем углу показывает текущую геолокацию.
- Переключатели слоёв (`Зона 1.2`, `Зона Б.1`) доступны на карте справа сверху.

## Обновление офлайн-данных

Если нужно обновить набор линий улиц:

```bash
node scripts/build_offline_data.mjs
node scripts/download_offline_tiles.mjs
```
